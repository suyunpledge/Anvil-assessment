# Anvil 三模块原生集成审查

日期：2026-10-17。基线：Anvil `assessment` / `485a741`。本次改动保留在工作区，未推送外部仓库。

## 集成结果

Anvil、HR、SVSG 现由 `anvil.py` 在同一进程运行。HR 与 SVSG 的固定源码快照位于 `vendor/`；记忆、视觉和编码模型复用统一模型传输与出网闸。独立 HR :8001、SVSG :3002 和网关 :8098 不再是考核版运行依赖。

配置集中到 `anvil.toml`，工作台及 API 同源，运行目录集中到 `.runtime/`。完成“任务检索历史 → 看图与工具执行 → gate 验证 → 用户确认 → 成功知识入库 → 后续任务召回”的闭环。原独立服务的源码、未提交修改、数据库和后台任务均未被覆盖或删除。

## 审查发现与修复

| 问题 | 影响 | 修复与证据 |
|---|---|---|
| 控制台拒绝仍调用 confirm，后端忽略 approve | 用户拒绝的修改可能被写回 | 前端拒绝走 cancel；后端兼容 `approve=false`；API 级回归断言源文件未变 |
| 待确认工单取消后仍可确认 | 取消意图失效 | 确认检查取消标志，待确认取消转 cancelled；拒绝后二次确认失败 |
| 确认前删除真实文件或篡改暂存文件 | 可能重建已删除文件，或提交未验证内容 | 比对真实文件原版本和暂存验证版本；两种攻击均有回归 |
| 运行器包装未透传视觉授权属性 | 引擎装了工具，模型看不到 | 透传运行时工具属性；真实模型可见 schema 与引擎授权两层验证 |
| 工具权限写入持久化画像 | 后续代码单可能继承视觉能力 | 使用仅驻内存的 runtime_toolsets；新实例及普通工单不暴露视觉 |
| 原视觉 L3 仅接收检测文字，没有图片 | 声称接视觉模型却未实际看图 | 实际传入像素；记录图像摘要、IR、提示与断言；像素输入回归 |
| 原 L1.5 是空复核桩 | 低置信实例只能降级 | 原生适配改为本地视觉模型的区域复核；失败或实例集合不符仍保守降级 |
| HTTP 200 的 rejected 状态被当成成功 | 拒绝结果可能用于写代码 | 工具层严格区分交付、拒绝、待复审；视觉工单未成功看图不能完成 |
| HR 只有检索，无成功经验入库 | 文档承诺的记忆闭环不成立 | 确认后持久化 outbox，后台入库；失败保留并重试；确认前不会入库 |
| 共享 HR 缺少项目作用域 | 项目间历史串入上下文 | 真实项目路径哈希隔离；暂存仍映射原项目；真实 HR 存储隔离回归 |
| HR 全文字段使用错误 | 关联全文丢失 | 读取 `chunk_text` / `full_text`，保留来源 ID |
| 小文件全文回退丢掉记忆 | 日志“召回”不等于模型实际收到 | 全文回退单独保留 memory_text；记录实际消息验证进入上下文 |
| 预算使用理论 ctx_max | 可能超出模型实际窗口 | 使用编辑节点实际窗口；计入 section 标题开销；有效窗口回归 |
| 本地嵌入冷启动超时 | 确认后记忆待入库失败 | 原生默认单次嵌入预算改为60秒；失败保留待入库记录，不伪报成功 |
| 查询重复计算同一向量 | 重复模型调用、显存切换与等待 | 每项目有界向量缓存；空库不调用嵌入；调用次数回归 |
| Qwen3.5 估错补丁行号 | 真机误删相邻 main 函数，反复修复 | 本模型 schema 收窄为原文替换；其他模型 registry 不变；真机重跑与 schema 隔离回归 |
| 修复轮仍开长思考 | 小模型任务延迟增加 | Qwen3.5 edit/repair 均关闭思考；保留确定性 gate |
| generated_profiles 存在非法 future 导入及未定义 m | 画像模块导入失败，被 loader 静默跳过 | 修复导入顺序和证据字符串；模块导入、compileall 和未定义名字扫描通过 |
| adapter_factory 的 Dict 未导入，未知适配器抛 SystemExit | 注解解析异常；线程退出后工单可能挂 running | 补齐导入，库函数抛 ValueError；未知模型路径进入 failed，有回归 |
| 网关 async 路由直接执行阻塞模型请求 | 模型运行期间服务响应受阻 | HTTP 网关用线程执行阻塞调用；原生内部调用直接复用传输，无 HTTP 自调用 |
| 日志名毫秒级碰撞、各模块无共同工单标识 | 并发记录覆盖，难以重建接入过程 | UUID 文件名 + 原子替换 + 工单作用域；并发日志回归 |
| 老启动方式、端口、演示路径、源码同步文档失真 | 换机器与现场演示易失败 | 单进程入口、相对运行路径、固定依赖、doctor、演示生成器；旧 core 镜像同步禁止覆盖 |
| 打包未排除虚拟环境和密钥配置 | 交付包可能携带无关文件 | 排除 .venv、缓存、.env、运行数据；源码快照保留来源和哈希 |

真实模型验收报告保存在 `.runtime/acceptance/<run-id>/report.json`，工单记录在同目录 `records/`。离线替身测试与真实推理结果分开报告。首次真机验证发现 Qwen 行号补丁失败；收窄契约后继续验收，不以单测代替模型集成效果。

## 当前能力边界

编码任务仍为单文件 Python 修改，三道 gate 验证的是已有程序化规则和测试，并非任务语义的形式化证明。视觉以检测器支持的物体及关系为主；区域复核复用同一视觉模型，不能宣传为独立模型交叉验证或通用 OCR。记忆按项目存储，原独立 HR 中其他应用的历史不会自动迁入。

配置包含明确的调用、生成长度、上传大小和单次请求超时上限；本地硬件速度、模型冷启动与上下文大小仍影响总耗时。`--doctor` 只检查依赖和资源就绪，不能代替完整推理验收。
